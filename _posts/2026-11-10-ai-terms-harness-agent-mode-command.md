AI 뉴스를 읽거나 ChatGPT, Claude를 실무에 쓰다 보면 하루가 멀다 하고 낯선 용어들이 쏟아집니다.

- **"에이전트(Agent)가 대세라는데 기존 모델이랑 뭐가 다르지?"**
- **"Codex랑 Claude Code는 둘 다 코딩 AI 아닌가?"**
- **"하네스(Harness), 모드(Mode), 슬래시 명령어는 또 뭐지?"**
- **"요즘 다들 말하는 MCP(Model Context Protocol)는 도대체 뭐야?"**

개념이 머릿속에서 뒤엉켜 헷갈리는 분들을 위해, 복잡한 수식과 전공 용어 대신 **'식당 주방'**과 **'C타입 충전기'** 같은 일상 비유로 깔끔하게 정리했습니다. 앞으로 헷갈리는 핵심 AI 단어들은 계속해서 이곳에 집대성하여 업데이트합니다.

---

## 🍽️ 1. Codex vs Claude Code vs 에이전트: 무슨 차이일까?

가장 먼저 헷갈리는 세 단어부터 서열을 정리해 보겠습니다.

### ① 에이전트(Agent)란?
- **주방 비유**: 레시피만 알려주는 게 아니라, 직접 냉장고에서 재료 꺼내고 칼질하고 불 켜서 찌개 완성할 때까지 혼자 판단하며 일하는 **'요리사'**입니다.
- **기술적 정의**: 단순히 질문에 텍스트로 답하는 챗봇(LLM)을 넘어, **주어진 목표를 달성할 때까지 스스로 계획을 세우고, 파일 읽기·검색·터미널 실행 같은 도구(Tools)를 자율적으로 호출하며 루프(Loop)를 도는 시스템**입니다.

### ② Codex: 코드 잘 외운 레시피북 (모델)
- **주방 비유**: 주방 도구를 쥘 줄은 모르고 머릿속에 요리 지식만 잔뜩 든 **'요리책 두뇌'**입니다.
- **기술적 정의**: 2021년 OpenAI가 GPT-3를 수많은 오픈소스 코드로 파인튜닝했던 **'순수 코드 생성 모델(LLM)'**입니다. 초기 GitHub Copilot의 엔진으로 쓰였으며, 개발자가 타이핑하는 코드의 다음 줄을 '자동 완성'해 주는 데 집중했습니다. 스스로 파일을 열거나 컴파일 에러를 고칠 손발은 없었습니다.

### ③ Claude Code: 손발까지 달린 총괄 셰프 (코딩 에이전트)
- **주방 비유**: 똑똑한 요리 지식(Claude 3.7 Sonnet)에 칼과 프라이팬(터미널, 파일 수정 도구)을 쥐어준 **'코딩 전문 총괄 셰프'**입니다.
- **기술적 정의**: Anthropic이 개발한 **터미널(CLI) 기반의 풀 코딩 에이전트 완제품**입니다. 사용자가 "이 버그 고쳐줘"라고 목표만 주면, 에이전트가 알아서 프로젝트 코드베이스를 검색하고, 버그가 난 파일을 찾아 수정하고, 테스트를 돌려 성공 여부를 확인한 뒤 git 커밋까지 스스로 완결합니다.

> 💡 **한 줄 정리**:  
> **Codex**는 '코드 잘 쓰는 두뇌(모델)'였고, **Claude Code**는 그 두뇌에 손발(터미널·도구)을 달아 직접 개발 업무를 해치우는 '전문 에이전트 완제품'입니다.

## 🧰 2. 하네스, 모드, 명령어: 주방의 통제 시스템

에이전트가 똑똑하게 일하려면 안전한 주방 환경과 통제 시스템이 필요합니다. 여기서 등장하는 3대 개념이 하네스, 모드, 명령어입니다.

### ① 하네스 (Harness): 안전벨트이자 작업대
- **일상 비유**: 강아지 산책용 가슴줄(Harness)이나 암벽 등반용 안전벨트처럼, 에이전트가 딴길로 새지 않도록 감싸주는 **'작업 틀이자 통제 하네스'**입니다.
- **기술적 정의**:
  - **Agent Harness (실행 런타임)**: AI 두뇌 혼자서는 터미널을 열거나 사내 DB에 함부로 접근하면 위험합니다. 따라서 정해진 권한 안에서 안전한 도구만 쓰도록 감싸주고 통제하는 샌드박스 실행 환경입니다.
  - **Eval Harness (평가 틀)**: AI 모델의 실력을 공정하고 객관적으로 채점하기 위해 표준 시험 문제를 내고 채점하는 테스트 벤치마크 환경을 뜻합니다.

### ② 모드 (Mode): 요리사의 업무 태도 스위치
- **일상 비유**: 요리사의 **'상황별 업무 모드'**입니다.
- **기술적 정의**: 에이전트 도구(Cursor, Claude Code 등)에서 상황에 따라 AI의 행동 권한과 방식을 바꾸는 스위치입니다.
  - `Chat 모드`: 코드를 직접 건드리지 않고, 질문에 답변과 조언만 해주는 읽기 전용 모드.
  - `Plan / Architect 모드`: 바로 코드를 뜯어고치지 않고, 어떤 파일을 어떻게 수정할지 전체 아키텍처 설계도부터 짜는 모드.
  - `Agent / Act 모드`: 직접 터미널을 치고 파일을 열어 코드를 수정·실행하는 자율 실행 모드.

### ③ 명령어 (Command / Slash Command): 주방 전용 단축키
- **일상 비유**: 일일이 길게 설명하기 귀찮을 때 누르는 **'원터치 단축키'**입니다.
- **기술적 정의**: 챗봇이나 에이전트에게 자주 반복하는 복합 명령을 슬래시(`/`) 한 방으로 지시하는 매크로 기능입니다.
  - `/commit`: Git 변경점을 분석해서 커밋 메시지를 규격대로 쓰고 바로 커밋해라.
  - `/review`: 현재 작성된 코드의 보안 취약점과 성능 병목을 리뷰해라.
  - `/init`: 현재 프로젝트 폴더 구조를 파악하고 기본 설정을 구성해라.

## 🔌 3. MCP (Model Context Protocol): AI계의 표준 C타입 USB 단자

최근 앤트로픽(Anthropic)이 주도하여 AI 업계의 새로운 표준으로 자리 잡고 있는 핵심 규격입니다.

### ① 일상 비유: 만능 C타입 충전 케이블
- 과거에는 스마트폰 제조사마다 충전 단자(24핀, 8핀, 마이크로 5핀)가 제각각이라, 기기를 바꿀 때마다 전용 젠더와 케이블을 새로 사야 했습니다.
- 지금은 **USB-C 타입 단자 하나**로 스마트폰, 노트북, 태블릿, 이어폰을 가리지 않고 전부 연결하고 충전합니다.
- **MCP는 바로 이 'C타입 표준 단자'를 AI와 기업 데이터·도구 사이에 구현한 표준 규격**입니다.

### ② 기술적 정의: 왜 MCP가 대세가 되었을까?
- **과거의 방식 (독자 규격 젠더)**:
  AI 모델을 사내 PostgreSQL 데이터베이스, 깃허브 코드 저장소, 슬랙 메신저, 노션 문서에 연결하려면, 개발자가 각 서비스마다 API 연동 파이프라인과 커스텀 플러그인을 일일이 따로 개발해야 했습니다. 연동할 서비스가 10개면 10개의 커넥터를 제각각 개발하고 유지보수해야 했습니다.
- **MCP 방식 (글로벌 오픈 표준 규격)**:
  데이터 소스(서버)와 AI 애플리케이션(클라이언트) 사이의 통신 규격을 하나로 표준화했습니다.
  - 데이터나 도구를 가진 곳은 표준 규격에 맞춘 **'MCP 서버'** 하나만 띄워둡니다.
  - Claude Desktop, Claude Code, 또는 사내 AI 에이전트는 **'MCP 클라이언트'**로서 그 단자에 플러그만 꽂으면(Connect) 코드 한 줄 추가 개발 없이 즉시 사내 DB를 조회하고, 슬랙 메시지를 보내고, 깃허브 PR을 생성할 수 있습니다.

> 💡 **한 줄 정리**:  
> **MCP**는 AI가 사내 DB, 파일, 외부 도구와 통신할 때 복잡한 커스텀 개발 없이 플러그 앤 플레이로 즉시 연결되도록 만든 **'AI 전용 오픈 표준 통신 규격'**입니다.

## 🎯 4. AI Solution Architect(SA) 실무 인사이트

엔터프라이즈 기업 고객에게 AI 시스템을 제안하는 아키텍트라면, 이 용어들을 다음과 같은 관점으로 연결해 볼 수 있습니다.

1. **단순 LLM에서 복합 에이전트 아키텍처로의 전환**:
   기업들은 이제 "챗봇 하나 놔주세요"를 원하지 않습니다. 사내 API와 DB에 연결되어 실제 결재, 데이터 분석, 고객 응대 업무를 끝까지 완결하는 **'에이전틱 워크플로우(Agentic Workflow)'**를 요구합니다.
2. **거버넌스와 하네스의 중요성**:
   에이전트가 자율성을 가질수록 기업 고객은 "AI가 사내 중요 데이터를 지우거나 외부에 유출하면 어쩌죠?"라고 묻습니다. 이때 SA는 안전한 권한 통제, 감사 로깅, 가드레일을 제공하는 **'Enterprise Agent Harness'** 아키텍처를 제시할 수 있어야 합니다.
3. **인간과의 협업(Human-in-the-loop) 인터페이스**:
   모드(Mode)와 명령어(Command)는 인간 개발자가 AI의 자율성을 어느 수준까지 허용할 것인가를 결정하는 실전 인터페이스입니다. 중요 결재나 코드 배포 단계에서는 사람의 승인을 거치도록 설계하는 것이 프로덕션의 기본 원칙입니다.
4. **MCP를 활용한 초고속 엔터프라이즈 시스템 통합**:
   과거에는 고객사 레거시 DB나 ERP에 AI를 붙이려면 수개월짜리 대규모 SI 연동 개발이 필요했습니다. 하지만 SA가 표준 MCP 아키텍처를 제시하면, 고객사는 기존 코드를 건드릴 필요 없이 표준 MCP 서버만 열어둠으로써 AI 연동 구축 기간을 수개월에서 '수일'로 획기적으로 단축할 수 있습니다.
